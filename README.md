# מחשבונים פיננסיים ופנסיוניים — סביבת תצוגה

גרסת תצוגה עצמאית של שמונת המחשבונים שנבנו עבור
[amnonbahar.co.il](https://amnonbahar.co.il).
נועדה לבדיקה ולשיתוף בלבד — **לא** לאינדוקס ולא לתחליף לאתר החי.

כל הקבצים יושבים בשורש אחד, בלי תת-תיקיות — כדי שאפשר יהיה להעלות
את כולם בבת אחת דרך ממשק ההעלאה של GitHub.

## איך מעלים ל-GitHub Pages

1. ליצור ריפו חדש (למשל `amnonbahar-calculators`).
2. להעלות את כל הקבצים לשורש הריפו (`Add file` → `Upload files`, לגרור את כולם יחד).
3. `Settings` → `Pages` → תחת *Build and deployment*, `Source: Deploy from a branch`,
   `Branch: main` ותיקייה `/ (root)` → **Save**.
4. אחרי דקה-שתיים האתר יהיה זמין בכתובת
   `https://<שם-המשתמש>.github.io/<שם-הריפו>/`.

כל הנתיבים בקבצים **יחסיים**, ולכן זה עובד גם בתת-תיקייה של GitHub Pages,
גם בריפו בשם `<user>.github.io`, וגם בפתיחה ישירה של `index.html`
מהמחשב בלחיצה כפולה — בלי שרת.

## הסרגל הזמני

הסרגל הכהה בראש כל עמוד (`<div class="pv-bar">`) הוא **תוסף תצוגה בלבד**
ואינו קיים באתר החי. כדי להיפטר ממנו: למחוק את הבלוק מה-HTML ואת
`preview.css` ו-`preview.js` — שאר העמוד לא מושפע.

## מה שונה מהאתר החי

- אין Google Tag Manager / Analytics.
- אין טופס השארת פרטים — כפתורי הפעולה מובילים ל-WhatsApp.
- אין הדר, פוטר ופאנל נגישות של האתר; במקומם סרגל התצוגה ופוטר מוקטן.
- כל קישור לעמוד תוכן אחר (פנסיה, קרן השתלמות וכו') נפתח באתר החי בטאב חדש.
- כל העמודים מסומנים `noindex, nofollow`.

## הסתייגות

המחשבונים הם **אומדן להמחשה בלבד**. אינם ייעוץ, אינם המלצה ואינם הבטחת
תשואה. כל החישובים רצים בדפדפן של הגולש בלבד — שום נתון לא נשלח לשרת
ולא נשמר.
